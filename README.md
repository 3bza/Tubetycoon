## Convert to APK in Android Studio
1. Download and install Android Studio from the official Android developer website.
2. Extract this ZIP.
3. Open Android Studio > Open.
4. Select the `CreatorEmpire_Pro_Android` folder.
5. Wait for Gradle Sync and install any SDK components Android Studio requests.
6. From the menu choose:
   Build > Build Bundle(s) / APK(s) > Build APK(s)
7. When the build finishes, click "locate".
8. The APK is normally in:
   app/build/outputs/apk/debug/app-debug.apk
9. Copy that APK to your Android phone and install it.

For a Play Store release later, use Build > Generate Signed Bundle / APK.
